# Nivya J — Portfolio

A responsive React + TypeScript portfolio starter with a premium dark-tech visual style.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Open Terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Build for deployment
```bash
npm run build
npm run preview
```

## Personalize before publishing
- Confirm project descriptions and dates.
- Add the AirShield repository URL in `src/App.tsx`.
- Add certificate links if available.
- Add a PDF resume and update the resume button/link when ready.
- Confirm that the SIH description and every listed achievement are accurate.
- Adjust or remove illustrative skill bars in `src/App.tsx`.
- Add or remove any technology you cannot yet confidently discuss.

## Deploy
You can import this project into a GitHub repository and deploy it with Vercel. Choose the repository, keep the build command `npm run build`, and the output directory `dist`.
